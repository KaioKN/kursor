# Kursor

Утилита для мыши на macOS, личная замена LinearMouse. Живёт в строке меню.

## Что умеет

- **Стабилизация клика.** Пока кнопка зажата, мелкие сдвиги (по умолчанию до 4 px за 200 мс) проглатываются. Клик не превращается в перетаскивание, отпускание доставляется в точку нажатия. Если сдвинуть дальше или держать дольше, перетаскивание работает как обычно.
- **Фильтр дребезга**, **сторож залипших кнопок** и **окно диагностики кликов**: сдвиг при каждом клике, итог и рекомендуемый допуск.
- **⌘ + колесо → щипок**, как на трекпаде: приложения получают настоящий жест увеличения. Для приложений из списка вместо жеста нажимается ⌘= / ⌘−. Есть smart zoom (двойной тап) и поворот (⌘⌥ + колесо).
- **Плавный скролл** с инерцией и ускорением. Реверс задаётся отдельно для каждой мыши и для трекпада.
- **Средняя кнопка**: зажать и тянуть, чтобы прокрутить документ, или автоскролл как в Windows.
- **Указатель**: своя скорость, без ускорения или с ускорением macOS, отдельно по устройствам. **Снайперский режим** замедляет курсор, пока зажата кнопка. Переброс курсора на следующий монитор.
- **Кнопка-жест**: удерживать и вести. ←/→ переключают рабочие столы, ↑ открывает Mission Control, ↓ — App Exposé.
- **Действия на боковые кнопки**: назад/вперёд, рабочие столы, Mission Control и т. д.
- **Фокус следует за курсором**: окно под курсором активируется после перехода на другой монитор (или всегда), чтобы первый клик сразу срабатывал.
- Профили по устройствам и импорт настроек из LinearMouse.

## Сборка

```sh
./scripts/make-cert.sh        # один раз: локальный сертификат, чтобы macOS не сбрасывала разрешения после пересборки
./scripts/bundle.sh --install # сборка, установка в ~/Applications и запуск
swift test                    # юнит-тесты логики
```

После первого запуска выдайте разрешения «Универсальный доступ» (обязательно) и «Мониторинг ввода» (для профилей по устройствам). Закройте LinearMouse и уберите его из автозапуска.

Конфиг: `~/Library/Application Support/Kursor/config.json`. Исходные настройки указателя сохраняются в `pointer-originals.json` рядом и восстанавливаются при выходе.

## Устройство

- `Sources/KursorCore/EventTap`: перехват событий на уровне HID на отдельном потоке (`Pipeline.swift` связывает все функции).
- `Sources/KursorCore/Features`: каждая функция — чистая машина состояний, покрытая тестами.
- `Sources/KursorCore/Synth`: синтетические жесты, скролл, клавиши, действия Dock.
- `Sources/KursorCore/Devices`: определение активной мыши (IOHIDManager) и скорость указателя (свойства HID-сервиса).
- `Sources/Kursor`: SwiftUI (строка меню, настройки, диагностика).

## Благодарности

- [LinearMouse](https://github.com/linearmouse/linearmouse) (MIT): подход к скорости указателя через свойства `IOHIDServiceClient`, к системным шорткатам рабочих столов и к уведомлениям Dock.
- [Mac Mouse Fix](https://github.com/noah-nuebling/mac-mouse-fix) (MMF License): номера недокументированных полей `CGEvent` для жестов щипка, поворота и smart zoom (изначально из CalfTrail Touch) и приём заморозки курсора через `CGWarpMouseCursorPosition`. Код не копировался.
